# Junkfeathers Machine

GeneratePress child theme for junkfeathers.com.

## Install

1. In WordPress admin, go to Appearance > Themes > Add New > Upload Theme.
2. Upload junkfeathers-machine.zip.
3. Activate "Junkfeathers Machine".
4. Confirm the site still looks normal.
5. Start adding Junkfeathers-specific CSS in style.css.

## Safety

- Do not edit the parent GeneratePress theme directly.
- Keep secrets out of this folder.
- Back up the site before major changes.
