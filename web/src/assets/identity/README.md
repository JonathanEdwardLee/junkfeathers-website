# Pygmalion Visual Identity Assets

This folder is reserved for the canonical Junkfeathers visual identity assets (including SVG logos, dead-bird marks, and console animations) once they are finalized and handed off by **Pygmalion**.

## Current Boundary
* **No placeholders**: Do not insert temporary drawings, generic bird icons, or approximated SVG paths.
* **Text-only fallback**: The Astro template utilizes standard monospace text rendering for names and headers until assets are approved.
* Refer to [PYGMALION_ASTRO_INTEGRATION_BOUNDARY_V1.md](../../../../docs/architecture/PYGMALION_ASTRO_INTEGRATION_BOUNDARY_V1.md) for full governance details.
